Soul of Sri Lanka 

Soul of Sri Lanka is a responsive travel website that showcases Sri Lanka's destinations, culture, food, and travel experiences. It helps visitors explore places of interest through destination pages, a visual gallery, and travel guides.

Features
- Home page introducing Sri Lanka and its attractions
- Destination listings with information about places to visit
- Image gallery showcasing Sri Lankan landmarks and experiences
- Travel guide with useful travel information
- Contact form for visitor messages
- PHP-based data handling with JSON files for storing and retrieving information
- Responsive layouts built with Bootstrap
  
Technologies Used
- HTML5
- CSS3
- JavaScript and jQuery
- Bootstrap 5
- PHP
- JSON
  
Getting Started
This project includes PHP files, so run it using a local PHP server such as XAMPP.
1. Download or clone this repository.
2. Extract the project folder into the XAMPP htdocs directory.
3. Open the XAMPP Control Panel and start Apache.
4. In your browser, visit:
   http://localhost/Soul%20of%20Srilanka/index.html
Some pages and data features rely on PHP. Open the project through localhost rather than directly opening the HTML files.

Project Structure
- index.html – Main home page
- destinations.html / destinations.php – Destination information
- Gallery.html – Sri Lankan photo gallery
- travel-guide.html – Travel guide
- contact.html / Contact.php – Contact page and form handling
- *.php – Server-side data handling
- *.json – Data storage
- Images/ and gallery images/ – Website images

Purpose
This project was developed as a web development project to present Sri Lanka as a travel destination while practising front-end design and basic server-side data handling.
